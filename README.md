# Bday project

Build a complete, polished, interactive birthday website that feels like a **personal romantic story game / visual novel**, created as a one-of-a-kind digital birthday gift for my boyfriend.

This is NOT a normal birthday website, NOT a generic romantic template, and NOT a corporate-looking website.

The experience should feel like he is **playing through a small story that was personally made for him**.

The entire website should be one continuous journey where every scroll or interaction reveals another chapter of the story.

## CORE CONCEPT

Theme:

**A romantic neon story game about us.**

The visual style should combine:

* dark neon game UI
* romantic atmosphere
* dreamy night aesthetic
* subtle RPG / visual-novel elements
* magical details
* elegant glowing effects
* intimate handwritten/letter moments

Think:

**romantic RPG + visual novel + dreamy digital scrapbook + birthday game**

Do NOT make it look like a typical RGB gamer website.

Avoid excessive rainbow RGB, aggressive gaming graphics, cyberpunk overload, or cheesy Valentine's Day visuals.

The relationship and birthday should remain the main story.

His interests should appear as **small personal discoveries throughout the journey**, rather than separate themed sections.

Use a dark background:

* almost-black
* deep navy
* charcoal
* very dark purple

Main accent colors:

* neon purple
* electric blue

* white
* subtle pink

Use:

* controlled neon glow

* faint gradients

* floating particles
* subtle grid patterns
* very subtle scanline effects
* atmospheric background lighting

Everything should feel polished and intentional.

Do NOT overuse glow.

The site should feel elegant even though it has a game aesthetic.

---

# IMPORTANT UX RULE

The website should feel like a **story**, not a collection of unrelated website sections.

Each chapter should naturally transition into the next.

Use:

* cinematic fades
* scroll-triggered animations
* gentle parallax
* text appearing gradually
* objects fading or blooming into the scene
* smooth section transitions

Avoid:

* abrupt section changes
* excessive animations
* animation on every single element
* distracting effects
* huge amounts of text appearing simultaneously

The user should always understand:

1. where they are
2. what they can interact with
3. what happens next
